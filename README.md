# BikeBuilder

## Une vraie navigation web

Le site propose maintenant une expérience navigable :

- accueil `/` ;
- configurateur `/builder` ;
- comparateur `/compare` ;
- configurations `/saved` ;
- menu mobile coulissant ;
- overlay d’aide accessible avec le bouton `?` en bas à droite ;
- transitions d’ouverture et fermeture ;
- liens cohérents entre toutes les pages.

## Lancer le site

```bash
npm install
npm run dev
```

Ouvre http://localhost:3000. Les données et prix sont explicitement en mode démonstration.
